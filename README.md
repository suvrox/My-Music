# My-Music

A modern, responsive web music streaming player built with Next.js, TypeScript, Tailwind CSS, and YouTube Data API.

## Features

- **YouTube Music Streaming**: Seamless audio playback powered by YouTube IFrame API with intelligent fallback and rate-limit circuit breaking.
- **Dynamic Recommendations & Continuous Playback**: Automatically queues related tracks and suggestions after each song.
- **Rich Responsive UI**: Optimized for all devices—featuring desktop sidebars and an industry-standard mobile floating mini-player with full-screen Now Playing modal sheet and bottom tab bar.
- **Search & Explore**: Live YouTube search for songs and artists with category/genre browsing.
- **Playlists & Library**: Create and manage custom playlists, save Liked Songs, and track listening history.

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the player.

## Build

```bash
npm run build
```
